Try it on Claude Desktop

Add to your claude_desktop_config.json file: 

{
  "mcpServers": {
            "querysculptor": {
            "command": "npx",
            "args": [
                "mcp-remote",
                "https://querysculptor.com/mcp"
            ]
        }
  }
}

Privacy Policy

Privacy-First Approach

QuerySculptor is designed with privacy in mind. We minimize data collection and do not store personal information.

Last updated: January 2025

1. Introduction

This Privacy Policy explains how QuerySculptor ("we", "our", or "the Service") collects, uses, and protects information when you use our experimental demo service.

2. Information We Collect

2.1 Session Data

When you use the MCP tools, we temporarily store:

  • Session identifiers: Randomly generated IDs to track your query-building session
  • Query structure: The GraphQL queries you build during a session
  • Session metadata: Timestamps and operation types

Session data is automatically deleted after 1 hour of inactivity or when you end your session.

2.2 Analytics (Optional)

If you consent, we use PostHog to collect anonymous usage analytics:

  • Page views and feature usage patterns
  • Browser type and general location (country level)
  • Session duration and interaction patterns

You can opt out of analytics at any time using the cookie consent banner. We do not collect personal identifiers, names, email addresses, or account information.

2.3 Server Logs

For security and debugging purposes, we may log:

  • IP addresses (for rate limiting)
  • Request timestamps
  • Error messages (without sensitive data)

Server logs are retained for up to 7 days.

3. Information We Do NOT Collect

  • Personal identification information (names, emails, phone numbers)
  • Authentication credentials or API keys you use with external GraphQL APIs
  • The actual data returned from GraphQL query executions
  • Financial or payment information

4. How We Use Information

We use collected information to:

  • Provide and maintain the query-building service
  • Enforce rate limits and prevent abuse
  • Improve the Service based on usage patterns
  • Debug issues and ensure security

5. Data Storage and Security

Session data is stored in Redis with encryption in transit. We implement security measures including:

  • HTTPS encryption for all connections
  • Rate limiting to prevent abuse
  • Automatic session expiration
  • SSRF protection for GraphQL endpoint validation

6. Third-Party Services

We use the following third-party services:

  • Vercel: Hosting and serverless infrastructure
  • Upstash Redis: Session storage
  • PostHog: Analytics (optional, with consent)

Each service has its own privacy policy governing their data practices.

7. Your Rights

You have the right to:

  • Opt out of analytics tracking
  • End your session at any time (which deletes session data)
  • Request information about data we hold (contact us via GitHub)

8. Children's Privacy

The Service is not directed at children under 13. We do not knowingly collect information from children.

9. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated revision date.
